# Job Description Snapshot — Airbnb Data Scientist, Platform

Source preserved from prior project artifact: LinkedIn job `4441237787`.

## Role
- Company: Airbnb
- Title: Data Scientist, Platform
- Team/community: MarTech Data Science Measurement
- Location: United States, remote eligible
- Pay range shown in captured posting: $151,000—$175,000 USD

## Core mandate
MarTech Data Science Measurement helps optimize marketing ROI through data-informed decision-making; defines and advances best practices for measuring and optimizing marketing impact; partners with Marketing, Finance, Engineering, and Product to provide actionable recommendations and tools based on timely and granular measurement.

## Typical day
- Causal inference: apply/develop methods to estimate effectiveness of marketing initiatives.
- Data analysis: pull data, analyze trends, create new features for measurement.
- Experimentation: design and analyze experiments evaluating marketing campaign impact.
- Collaboration: work with cross-functional teams and optimize marketing strategy.
- Thought leadership: create internal white papers and contribute to tech blog posts.

## Expertise
- Deep causal inference and experimentation knowledge.
- Statistical programming in Python or R.
- Database usage / SQL.
- Agentic coding.
- Clear stakeholder communication across technical levels.
- Track record solving business problems through data science.

## Preferred
- Marketing/consumer science and academic research.
- Bayesian modeling applications in marketing.
- Causal ML modeling.
- End-to-end models for data-driven decision-making.
